## Что обязательно проверить до зачетной игры

1. По п. **10.6** разрешена исключительно **DeepSeek V4 Flash**. Значение
   `deepseek-chat` по умолчанию и произвольное имя в настройках чата не
   доказывают соответствие. Получить подтвержденный API-идентификатор модели
   и разрешенный адрес у организаторов; проверить агент и чат отдельно.
2. Заполнить команду, ответственных, игру, подтвержденную модель и согласовать
   декларацию. Зафиксировать политику, corpus manifest и снимок исходников.
3. Объявить профиль автономности: рекомендуемый для декларации `normal`,
   `AGENT_YOLO=0`; исключить `force` и `yolo` из зачетного порядка работы.
   Это эксплуатационное ограничение: отдельного программного «зачетного
   замка» в коде пока нет.
4. Подтвердить разрешенные интерфейсы и действия. Аппаратные блокировки не
   отключать, не обходить и не подавлять, даже при подозрении на ложный сигнал.
5. Уточнить ответственного за безопасность, штатную аварийную остановку и
   порядок разрешения возобновления по пп. 9.3-9.4.
6. Проверить команды сброса защиты и изменения доверия к датчикам, уже
   имеющиеся в policy. Их воздействие и условия допустимости должны быть
   подтверждены; policy не является разрешением организаторов.

Это конкретные оставшиеся условия допуска, а не утверждение о полном
соответствии программы регламенту. Подробности: [матрица](REGULATION_COMPLIANCE.md).

## Запуск и роли компонентов

`start_panel.cmd` или `python launch_frontend.py --port 8080` открывает панель
на `http://127.0.0.1:8080/`. Она читает журнал и предоставляет справочный чат;
соединение с Куполом и управление оборудованием через эту панель не запускаются.
Агент запускается отдельно командой `python main.py` после подготовки `.env`
и проверки допуска.

```text
Телеметрия / meeting -> DomeAgent -> правила + RAG + разрешенная LLM
                                      -> проверка полномочий -> API -> проверка эффекта
                                      -> JSONL + state -> API просмотра -> светлый интерфейс
Чат и поиск интерфейса -> тот же KnowledgeService -> ответ с источниками
```

Пункт 9.2 и требования безопасности имеют приоритет над советом модели,
каталогом отказов, производственной выгодой и подтверждением в чате.
Сам факт доступности команды в программе не является разрешением ее применения.
