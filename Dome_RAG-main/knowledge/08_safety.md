# Безопасность

## О чём этот документ

Этот документ описывает правила безопасности на Куполе: зоны доступа, аппаратные блокировки, действия при инцидентах.

**Безопасность — приоритет над всем.** В случае противоречия между этим документом и любыми другими правилами действует этот документ.

**Главный принцип:** рисковать может техника, но не люди.

## Почему это важно

Купол — станция с силовой электрикой, накопителем энергии, нагревательными элементами, химическими реагентами и движущимся оборудованием. Ошибка в работе с этими системами может привести к травме, пожару, отравлению или повреждению станции.

Поэтому:

- зоны доступа разделены;
- аппаратные блокировки не отключаются;
- критические действия выполняет только человек;
- при угрозе люди имеют приоритет над задачей.

---

## Зоны доступа

Пространство Купола разделено на три зоны.

### Зона общего доступа

**Что это.** Цифровые системы, датчики, низковольтные стенды, интерфейсы управления.

**Кто имеет доступ.** Все члены экипажа.

**Что можно делать:**

- работать с телеметрией;
- отправлять команды через программные интерфейсы;
- работать с низковольтным оборудованием.

**Что нельзя делать:**

- обходить блокировки;
- использовать собственные средства связи;
- выходить за пределы разрешённых диапазонов команд.

### Рабочая зона

**Что это.** Производственное оборудование и ручные операции: пайка, механообработка, работа с химией.

**Кто имеет доступ.** Члены экипажа, прошедшие инструктаж, под надзором.

**Что можно делать:**

- паять;
- работать с 3D-принтером;
- работать с ЧПУ;
- работать с химией;
- выполнять механообработку;
- проводить измерения.

**Что нельзя делать:**

- работать без средств защиты;
- работать без вытяжки;
- работать без надзора;
- отключать аппаратные блокировки;
- заходить в зону повышенной опасности.

**Оборудование рабочей зоны:**

- 3D-принтер;
- ЧПУ фрезерный станок;
- паяльные станции;
- ванна для травления;
- вытяжка;
- осциллографы;
- лабораторные блоки питания;
- мультиметры.

### Зона повышенной опасности

**Что это.** Силовая электрика, накопитель энергии, нагревательные элементы, химические реагенты.

**Кто имеет доступ.** Прямой доступ запрещён.

**Что можно делать:**

- воздействовать дистанционно через программные интерфейсы;
- в пределах разрешённых диапазонов.

**Что нельзя делать:**

- заходить физически;
- отключать аппаратные блокировки;
- обходить защиту;
- работать с оборудованием зоны повышенной опасности руками.

**Оборудование зоны повышенной опасности:**

- силовая электрика;
- аккумуляторные батареи;
- инвертор;
- солнечные панели (электрическая часть);
- нагревательные элементы;
- концентрированные химические реагенты.

**Почему доступ запрещён:**

- высокое напряжение;
- риск короткого замыкания;
- риск пожара;
- риск химического ожога;
- риск отравления.

## Аппаратные блокировки

### Что это

Аппаратные блокировки — устройства, которые автоматически отключают или блокируют опасное оборудование при наступлении определённых условий.

**Примеры:**

- отключение при перегрузке по току;
- отключение при перегреве;
- отключение при утечке тока;
- отключение при срабатывании пожарной сигнализации;
- отключение при превышении порога CO₂.

### Ключевое правило

**Аппаратные блокировки не отключаются.** Ни экипажем, ни агентами Купола.

Это значит:

- нельзя программно обойти блокировку;
- нельзя физически отключить блокировку;
- нельзя изменить порог срабатывания;
- нельзя заставить агента обойти блокировку.

### Почему это важно

Аппаратные блокировки — последняя линия защиты. Если их отключить, система может выйти из-под контроля и привести к травме или пожару.

### Что делать, если блокировка сработала

1. Остановиться.
2. Не пытаться обойти блокировку.
3. Сообщить на пульт.
4. Выяснить причину срабатывания.
5. Устранить причину.
6. Сбросить блокировку штатным способом.
7. Продолжить работу.

**Срабатывание аварийной остановки — пауза, без последствий.**

## Кнопка аварийной остановки

### Где находится

- у дежурного;
- у оператора кризиса.

### Кто может нажать

- дежурный;
- оператор кризиса;
- любой член экипажа при реальной угрозе.

### Что происходит при нажатии

- работа ставится на паузу;
- оборудование отключается;
- последствий нет.

### Когда нажимать

- при реальной угрозе для человека;
- при возгорании;
- при поражении электрическим током;
- при отравлении;
- при любой ситуации, требующей немедленной остановки.

**Лучше нажать и ошибиться, чем не нажать и получить травму.**

## Электрическая безопасность

### Рабочие напряжения

- В зоне доступа — только безопасные сверхнизкие напряжения.
- Силовые напряжения — в зоне повышенной опасности, доступ запрещён.

### Правила

- Не работать с оборудованием под напряжением, если это не предусмотрено процедурой.
- Не касаться оголённых проводов.
- Не использовать повреждённые кабели.
- Не перегружать розетки и удлинители.
- Не работать с электрикой мокрыми руками.
- Не оставлять без присмотра включённое оборудование.

### При поражении электрическим током

1. Не касаться пострадавшего голыми руками.
2. Отключить питание.
3. Вызвать помощь.
4. Оказать первую помощь (если умеете).
5. Сообщить дежурному.

---

## Пожарная безопасность

### Причины возгорания

- короткое замыкание;
- перегрев оборудования;
- неисправность проводки;
- работа с легковоспламеняющимися жидкостями;
- искрение при пайке.

### Правила

- Не курить в Куполе.
- Не использовать открытый огонь без необходимости.
- Не оставлять без присмотра нагревательные приборы.
- Хранить легковоспламеняющиеся жидкости в закрытой таре, вдали от источников тепла.
- Знать, где находится огнетушитель.

### При возгорании

1. Сообщить на пульт.
2. Отключить питание (если безопасно).
3. Использовать огнетушитель (если умеете).
4. Покинуть зону.
5. Вызвать помощь.
6. Не тушить водой оборудование под напряжением.

---

## Химическая безопасность

### Где используется химия

- ванна для травления плат;
- очистка плат и контактов.

### Правила

- Работать только в рабочей зоне, под надзором.
- Использовать средства защиты: очки, перчатки, при необходимости — респиратор.
- Обеспечить работу вытяжки.
- Не принимать пищу и не пить в зоне работы с химией.
- Не смешивать химикаты без необходимости.
- Хранить химикаты в закрытой таре, с маркировкой.
- Утилизировать отходы по инструкции.

### При попадании химии на кожу

1. Промыть большим количеством воды.
2. Сообщить дежурному.
3. Обратиться за медицинской помощью.

### При попадании химии в глаза

1. Промыть большим количеством воды (не менее 15 минут).
2. Не тереть глаза.
3. Сообщить дежурному.
4. Обратиться за медицинской помощью.

### При вдыхании паров

1. Выйти на свежий воздух.
2. Сообщить дежурному.
3. Обратиться за медицинской помощью.

---

## Механическая безопасность

### Оборудование с движущимися частями

- ЧПУ фрезерный станок;
- 3D-принтер;
- вытяжной вентилятор.

### Правила

- Не касаться движущихся частей.
- Не оставлять работающее оборудование без присмотра.
- Не убирать стружку руками во время работы станка.
- Использовать защитные очки.
- Не работать в свободной одежде, которая может попасть в механизм.
- Не отключать защитные кожухи.

### При травме

1. Остановить оборудование.
2. Сообщить дежурному.
3. Оказать первую помощь.
4. Обратиться за медицинской помощью.

---

## Работа с вытяжкой

### Когда нужна вытяжка

- при пайке;
- при работе с химией;
- при работе с летучими веществами.

### Правила

- Вытяжка должна работать при активной пайке.
- Если вытяжка не работает — прекратить пайку.
- Если вытяжка отключилась — сообщить на пульт.
- Не отключать вытяжку без необходимости.

### Что делать, если вытяжка отключилась

1. Прекратить пайку.
2. Сообщить на пульт.
3. Проверить линию питания вытяжки.
4. Включить линию.
5. Продолжить работу.

---

## Режим работы экипажа

- При ухудшении самочувствия — сообщить дежурному.
- При усталости — ротация приветствуется.
- Переутомление — недопустимо. Оно снижает внимательность и повышает риск ошибки.
- При необходимости — сделать перерыв.
- Работа в одиночку в опасных зонах — запрещена.

---

## Связь и информация

### Локальная сеть

- Локальная сеть Купола изолирована от внешнего мира в рабочем режиме.
- Использование собственных средств связи не допускается.

### Персональные данные

- Персональные данные не передаются наружу.
- При подозрении на утечку данных — сообщить на большую землю.

### Пароли и ключи

- Не передавать пароли и ключи посторонним.
- Не хранить пароли в открытом виде.
- Не использовать чужие ключи.

---

## Действия при инцидентах

### Общий порядок

1. Остановиться.
2. Обеспечить безопасность — свою и окружающих.
3. Сообщить дежурному.
4. Оказать первую помощь (если умеете).
5. Не пытаться скрыть инцидент.

### Технический сбой, не связанный с заданием

1. Сообщить на большую землю.
2. Не пытаться самостоятельно устранить, если это опасно.
3. Работать в ограниченном режиме до устранения.

### Аварийная остановка

1. Нажать кнопку аварийной остановки.
2. Сообщить дежурному.
3. Дождаться разрешения на продолжение.

**Срабатывание аварийной остановки — пауза, без последствий.**

---

## Инструктаж

### Условие допуска

Прохождение инструктажа по безопасности — условие допуска к работе в рабочей зоне.

### Что включает

- инструктаж по электрической безопасности;
- инструктаж по пожарной безопасности;
- инструктаж по химической безопасности;
- инструктаж по механической безопасности;
- инструктаж по работе с вытяжкой;
- инструктаж по действиям при инцидентах.

### Периодичность

- перед началом смены — краткий инструктаж;
- при изменении условий работы — дополнительный инструктаж.

---

## Что запрещено

- Заходить в зону повышенной опасности.
- Отключать или обходить аппаратные блокировки.
- Использовать незарегистрированных агентов.
- Использовать собственные средства связи.
- Создавать реальный дефицит жизненно важных ресурсов для людей.
- Выводить агента за пределы разрешённой автономности.
- Работать без средств защиты.
- Работать без вытяжки при пайке.
- Работать без надзора.
- Курить в Куполе.
- Использовать открытый огонь без необходимости.
- Хранить легковоспламеняющиеся жидкости вблизи источников тепла.
- Смешивать химикаты без необходимости.
- Принимать пищу и пить в зоне работы с химией.
- Касаться движущихся частей оборудования.
- Убирать стружку руками во время работы станка.
- Отключать защитные кожухи.
- Скрывать инциденты.

---

## Что разрешено

- Работать с телеметрией.
- Отправлять команды через программные интерфейсы в разрешённых диапазонах.
- Работать в зоне общего доступа.
- Работать в рабочей зоне после инструктажа, под надзором, со средствами защиты.
- Использовать штатные каналы связи.
- Настраивать агентов Купола в подготовительной фазе.
- Останавливать работу при реальной угрозе.
- Обращаться за помощью.
