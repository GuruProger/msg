# Типы отказов

## О чём этот документ

Этот документ описывает типы отказов, которые могут возникнуть на Куполе. Он нужен, чтобы экипаж понимал, к чему готовиться, и мог правильно настроить агентов Купола.

Здесь описаны **классы** возможных отказов. Конкретные ситуации могут отличаться, но общие принципы остаются теми же.

## Как читать этот документ

Каждый раздел описывает один тип отказа. Для каждого типа указано:

- **Что происходит** — краткое описание.
- **Как заметить** — признаки в телеметрии.
- **Что может сделать человек** — ручное решение.
- **Что может сделать агент** — автоматическое решение.
- **Чего нельзя допустить** — к чему приводит бездействие.

## Два типа наблюдаемости

### Прямая наблюдаемость

Причина отказа видна сразу. Например, инвертор показывает код ошибки, щит показывает статус срабатывания защиты.

**Что делать.** Быстро распознать и действовать.

### Скрытая наблюдаемость

Причина отказа не видна. Виден только симптом. Нужна диагностика: сверка с другими датчиками, анализ истории, проверка альтернативных источников.

**Что делать.** Не действовать по первому сигналу, а сначала проверить.

---

## Категории отказов

Отказы делятся на категории по источнику:

1. **Сенсорные** — датчик врёт, залипает, шумит.
2. **Исполнительные** — реле, привод, команда не отрабатывает.
3. **Программные** — скрипт завис, процесс упал, утечка памяти.
4. **Сетевые** — потеря связи, коллизия, таймауты.
5. **Энергетические** — генерация, накопитель, инвертор.
6. **Производственные** — ЧПУ, 3D-принтер, пайка, травление.
7. **Средовые** — микроклимат, CO₂, влажность.
8. **Человеко-агентные** — конфликт решений, выход за границы.

## 1. Сенсорные отказы

### 1.1. Ложное завышение показаний

**Что происходит.** Датчик систематически завышает значение.

**Как заметить.** Показания датчика не согласуются с другими источниками.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Измерить реальное значение мультиметром или пирометром, сравнить.

**Что может сделать агент.** Сверить с независимым источником, пометить датчик как недостоверный, блокировать автоматические решения на его основе.

**Чего нельзя допустить.** Ложная тревога, отключение исправного оборудования.

### 1.2. Ложное занижение показаний

**Что происходит.** Датчик систематически занижает значение.

**Как заметить.** Показания ниже ожидаемых, но оборудование работает.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Измерить реальное значение, сравнить.

**Что может сделать агент.** Сверить с независимым источником, пометить как недостоверный.

**Чего нельзя допустить.** Ложное спокойствие, пропуск реального отказа.

### 1.3. Залипание на последнем значении

**Что происходит.** Датчик перестаёт обновляться, показывает последнее значение.

**Как заметить.** Значение не меняется длительное время, хотя должно.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Проверить, обновляется ли телеметрия, перезапустить датчик.

**Что может сделать агент.** Заметить отсутствие изменений, пометить как замороженный, предупредить.

**Чего нельзя допустить.** Решения на основе устаревших данных.

### 1.4. Залипание на максимуме шкалы

**Что происходит.** Датчик показывает максимум шкалы и не меняется.

**Как заметить.** Значение равно максимуму, не реагирует на изменения.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Понять, что значение физически невозможно, сбросить тревогу.

**Что может сделать агент.** Классифицировать как насыщение датчика, игнорировать, блокировать ложную тревогу.

**Чего нельзя допустить.** Остановка работы по ложной тревоге.

### 1.5. Резкий скачок

**Что происходит.** Датчик показывает резкий скачок за секунды.

**Как заметить.** Скорость изменения физически невозможна.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Понять, что скачок невозможен, игнорировать.

**Что может сделать агент.** Вычислить скорость изменения, классифицировать как ложный скачок, игнорировать.

**Чего нельзя допустить.** Ложная тревога, остановка.

### 1.6. Шум в данных

**Что происходит.** Показания датчика «прыгают».

**Как заметить.** Высокая дисперсия, корреляция с работой другого оборудования.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Найти источник помех, отключить его.

**Что может сделать агент.** Проанализировать шум, найти корреляцию с другим устройством, предупредить.

**Чего нельзя допустить.** Нестабильные данные, ложные срабатывания.

### 1.7. Обрыв связи (значение 0 или пусто)

**Что происходит.** Датчик отдаёт 0 или пустое значение.

**Как заметить.** Значение не соответствует реальности.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Проверить датчик физически, заменить.

**Что может сделать агент.** Классифицировать как отказ датчика, перейти на резервный источник, предупредить.

**Чего нельзя допустить.** Решения вслепую.

## 2. Исполнительные отказы

### 2.1. Залипание в состоянии ON

**Что происходит.** Реле не выключается по команде.

**Как заметить.** Линия потребляет энергию, хотя должна быть выключена.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Отключить линию через главный автомат.

**Что может сделать агент.** Отправить аппаратный сброс, предупредить.

**Чего нельзя допустить.** Перерасход энергии.

### 2.2. Задержка выполнения команды

**Что происходит.** Команда выключения выполняется с задержкой.

**Как заметить.** Команда отправлена, но линия продолжает работать.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Отключить вручную.

**Что может сделать агент.** Повторить команду, отправить аппаратный сброс.

**Чего нельзя допустить.** Перерасход, риск повреждения.

### 2.3. Ложное срабатывание защиты

**Что происходит.** Реле отключается по ложной тревоге.

**Как заметить.** Статус срабатывания, но реальной перегрузки нет.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Сбросить защиту вручную.

**Что может сделать агент.** Проанализировать историю, если ложное — сбросить, установить усиленный контроль.

**Чего нельзя допустить.** Остановка работы.

### 2.4. Переход в безопасный режим

**Что происходит.** Щит переводит все линии в состояние OFF.

**Как заметить.** Все розетки обесточены, на дисплее статус безопасного режима.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Выйти из безопасного режима через локальный интерфейс.

**Что может сделать агент.** Отправить команду выхода, восстановить линии по приоритету.

**Чего нельзя допустить.** Полная остановка.

### 2.5. Команда уходит в никуда

**Что происходит.** Команда отправлена, ответ успешный, но состояние не изменилось.

**Как заметить.** Состояние не меняется после команды.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Продублировать действие вручную.

**Что может сделать агент.** Проверить состояние после команды, повторить при расхождении.

**Чего нельзя допустить.** Критические команды не выполняются.

### 2.6. Дублирование команд

**Что происходит.** Одна команда выполняется несколько раз.

**Как заметить.** Реле щёлкают с высокой частотой, в логах повторы.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Очистить очередь.

**Что может сделать агент.** Внедрить защиту от дублирования, очистить очередь.

**Чего нельзя допустить.** Износ механики реле.

## 3. Программные отказы

### 3.1. Зависание скрипта

**Что происходит.** Скрипт перестаёт работать, но процесс не падает.

**Как заметить.** Данные не обновляются, команды не проходят.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Перезапустить скрипт вручную.

**Что может сделать агент.** Заметить отсутствие отклика, перезапустить.

**Чего нельзя допустить.** Потеря управления, устаревшие данные.

### 3.2. Падение процесса

**Что происходит.** Процесс аварийно завершается.

**Как заметить.** Сервис недоступен.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Перезапустить процесс.

**Что может сделать агент.** Перезапустить, предупредить.

**Чего нельзя допустить.** Потеря функциональности.

### 3.3. Утечка памяти

**Что происходит.** Процесс постепенно потребляет всё больше памяти.

**Как заметить.** Рост потребления памяти, замедление.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Перезапустить процесс.

**Что может сделать агент.** Следить за памятью, перезапустить до падения.

**Чего нельзя допустить.** Падение процесса.

### 3.4. Переполнение диска

**Что происходит.** Диск заполнен, логи не пишутся.

**Как заметить.** Ошибки записи, свободное место равно нулю.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Удалить старые логи.

**Что может сделать агент.** Следить за местом, удалять старые логи.

**Чего нельзя допустить.** Потеря данных для диагностики.

### 3.5. Медленный диск

**Что происходит.** Диск работает медленно.

**Как заметить.** Запросы с задержкой, время ожидания ввода-вывода растёт.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Завершить ресурсоёмкий процесс.

**Что может сделать агент.** Снизить частоту запросов, предупредить.

**Чего нельзя допустить.** Устаревшие данные.

### 3.6. Перегрев процессора

**Что происходит.** Процессор перегревается, производительность падает.

**Как заметить.** Температура выше порога, задержки.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Снизить нагрузку, улучшить охлаждение.

**Что может сделать агент.** Снизить частоту опроса, отключить второстепенные процессы.

**Чего нельзя допустить.** Устаревшие данные, опоздание команд.

### 3.7. Рассинхрон времени

**Что происходит.** Системное время на одном из устройств сдвигается.

**Как заметить.** Метки времени в логах не совпадают.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Синхронизировать время.

**Что может сделать агент.** Заметить рассинхрон, пометить логи как недостоверные, предупредить.

**Чего нельзя допустить.** Невозможность сопоставления событий.

### 3.8. Ошибка в автозапуске

**Что происходит.** После перезагрузки сервисы не стартуют.

**Как заметить.** Сервисы недоступны после перезагрузки.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Запустить сервисы вручную.

**Что может сделать агент.** Заметить отсутствие сервисов, запустить вручную.

**Чего нельзя допустить.** Потеря функциональности.

### 3.9. Конфликт версий

**Что происходит.** После обновления интерфейс изменился, старые вызовы не работают.

**Как заметить.** Команды возвращают ошибки.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Обновить скрипты вручную.

**Что может сделать агент.** Сверить версию, предложить обновлённый вызов.

**Чего нельзя допустить.** Потеря управления.

### 3.10. Переполнение очереди

**Что происходит.** Очередь событий переполнена, команды обрабатываются с задержкой.

**Как заметить.** Рост длины очереди, задержки, повторяющиеся записи.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Очистить очередь.

**Что может сделать агент.** Очистить очередь, увеличить лимит, предупредить.

**Чего нельзя допустить.** Таймауты, потеря событий.

### 3.11. Ограничение частоты запросов

**Что происходит.** Система блокирует слишком частые запросы.

**Как заметить.** Ответы с кодом «слишком много запросов».

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Перейти на ручное управление.

**Что может сделать агент.** Перейти на пакетную отправку команд.

**Чего нельзя допустить.** Невозможность быстрого реагирования.

### 3.12. Отказ сервера

**Что происходит.** Сервер приложений падает, все запросы возвращают ошибку.

**Как заметить.** Полная потеря связи.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Перезапустить сервер.

**Что может сделать агент.** Перейти на прямое управление, предупредить.

**Чего нельзя допустить.** Паралич системы.

### 3.13. Сбой DNS

**Что происходит.** Запросы к внешним сервисам не проходят.

**Как заметить.** Таймауты при обращении.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Взять управление на себя.

**Что может сделать агент.** Переключиться на локальный резерв.

**Чего нельзя допустить.** Деградация работы агентов.

## 4. Сетевые отказы

### 4.1. Коллизия IP-адресов

**Что происходит.** Два устройства получили одинаковый адрес.

**Как заметить.** Периодические потери связи с обоими устройствами.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Сменить адрес вручную.

**Что может сделать агент.** Заметить конфликт, сменить адрес, предупредить.

**Чего нельзя допустить.** Нестабильное управление.

### 4.2. Потеря Wi-Fi

**Как заметить.** Телеметрия замирает, команды не проходят.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Перезагрузить модуль связи.

**Что может сделать агент.** Переключиться на проводной резерв, предупредить.

**Чего нельзя допустить.** Потеря управления.

### 4.3. Обрыв кабеля

**Что происходит.** Обрыв кабеля между устройствами.

**Как заметить.** Устройство недоступно.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Заменить кабель.

**Что может сделать агент.** Переключиться на резерв, предупредить.

**Чего нельзя допустить.** Полная потеря управления.

### 4.4. Деградация оптического модуля

**Что происходит.** Оптический модуль деградирует, связь периодически теряется.

**Как заметить.** Периодические потери связи, короткие задержки.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Перезагрузить конвертер.

**Что может сделать агент.** Предупредить о деградации, переключиться на резерв.

**Чего нельзя допустить.** Полный обрыв.

### 4.5. Коллизия на шине

**Что происходит.** Одновременный опрос устройств создаёт конфликт.

**Как заметить.** Ошибки чётности, пропуски в телеметрии.

**Наблюдаемость.** Скрытая.

**Что может сделать агент.** Снизить частоту опроса, предупредить.

**Чего нельзя допустить.** Нестабильное управление.

### 4.6. Застревание переключения источника данных

**Что происходит.** Переключение источника данных зависает в промежуточном состоянии.

**Как заметить.** Устройство не отдаёт данные.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Перезагрузить устройство.

**Что может сделать агент.** Принудительно завершить переключение.

**Чего нельзя допустить.** Потеря телеметрии.

## 5. Энергетические отказы

**Что происходит.** Линия потребляет энергию без нагрузки.

**Что может сделать агент.** Пометить как утечку, отключить.

**Чего нельзя допустить.** Ускоренная разрядка накопителя.

### 5.2. Ложная балансировка

**Что происходит.** Система управления батареей запускает балансировку при высоком заряде.

**Как заметить.** Накопитель заблокирован, балансировка идёт.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Отменить балансировку вручную.

**Что может сделать агент.** Отменить балансировку.

**Чего нельзя допустить.** Агрессивная разрядка накопителя.

### 5.3. Деградация ёмкости накопителя

**Что происходит.** Данные о ёмкости занижены.

**Как заметить.** Система преждевременно отключает нагрузки.

**Наблюдаемость.** Скрытая.

**Что может сделать человек.** Сверить с историей.

**Что может сделать агент.** Пометить данные как недостоверные.

**Чего нельзя допустить.** Преждевременная остановка.

**Что может сделать человек.** Проверить пирометром.

**Что может сделать агент.** Пометить датчик как недостоверный, игнорировать снижение мощности.

**Чего нельзя допустить.** Снижение мощности.

### 5.7. Отключение MPPT

**Что происходит.** Инвертор отключает каналы съёма мощности с панелей.

**Как заметить.** Генерация падает на 40–50% или до нуля.

**Наблюдаемость.** Прямая.

**Что может сделать человек.** Перезагрузить инвертор.

**Что может сделать агент.** Включить каналы.

**Чего нельзя допустить.** Потеря генерации.

### 5.8. Программное занижение тока заряда

**Что происходит.** Ток заряда занижен программно.

**Что может сделать агент.** Сбросить лимиты.

**Чего нельзя допустить.** Потеря генерации.

### 5.9. Отказ вентилятора охлаждения

**Чего нельзя допустить.** Ложное отключение нагрузок.

## Что важно помнить

- **Главное — не пропустить отказ.** Ошибка сама по себе не страшна. Страшна ошибка, которую не заметили.
- **Прямая наблюдаемость** — действуй быстро.
- **Скрытая наблюдаемость** — сначала проверь.
- **Агент полезен снижением отвлечения, а не заменой человека.**
- **Критические действия — только человек.**
- **Безопасность — всегда первый приоритет.**
